# Ravelry AI Search

Semantic search for Ravelry knitting patterns using hybrid BM25 + vector retrieval, Cohere reranking, and GPT-4o-mini recommendations.

## Setup

### 1. Install dependencies

```bash
cd ravelry_v0
pip install -r requirements.txt
# or with uv:
uv pip install -r requirements.txt
```

### 2. Configure API keys

Create `ravelry_v0/.env`:

```
RAVELRY_USERNAME=your_ravelry_username
RAVELRY_PASSWORD=your_ravelry_api_password   # Basic Auth password from ravelry.com/pro/developer
OPENAI_API_KEY=sk-...
COHERE_API_KEY=...
```

### 3. Generate data (three steps, run from `ravelry_v0/`)

**Step 1 — Collect patterns from Ravelry API** (~8 000 patterns, takes ~30 min):

```bash
python collect_data.py
```

Writes `data/patterns.json`. Each pattern already includes a `text_for_embedding` field.

If you change `data_processor.py` and need to rebuild that field on an existing `patterns.json`:

```bash
python rebuild_text.py
```

**Step 2 — Generate embeddings** (OpenAI `text-embedding-3-small`, costs ~$0.10 for 8k patterns):

```bash
python rag.py
```

Writes `data/embeddings.npy`. Skips generation if the file already exists.

**Step 3 — (Optional) Run offline evaluation**:

```bash
python eval.py --version v2_reranked
```

Writes `data/eval_results_v2_reranked.json`. Requires Cohere API key. Adds a 7-second sleep between queries to stay within the free-tier rate limit.

## Run the app

```bash
cd ravelry_v0
streamlit run app.py
```

## Data files

`data/golden_set.json` — manually annotated evaluation set (tracked in git).

All other `data/` files are excluded from git and must be generated locally (see above):

| File | Size | Generated by |
|---|---|---|
| `data/patterns.json` | ~170 MB | `collect_data.py` |
| `data/embeddings.npy` | ~94 MB | `rag.py` |
| `data/eval_results_*.json` | ~4 KB each | `eval.py` |

## Architecture

```
Query
  └─ parse_query()          LLM extracts semantic query + structured filters
       └─ hybrid_search()   BM25 + cosine vector search fused with RRF (k=60)
            └─ reranked_search()  Cohere rerank-multilingual-v3.0
                 └─ app.py        Streamlit UI with sort + GPT-4o-mini recommendations
```
